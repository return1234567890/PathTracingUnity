## 0. 速查

| 问题 | 答案 |
|---|---|
| 方程有哪几项 | 消光（拿走）、发射（补回）、内散射（搬过来） |
| 有几个积分 | 两个：沿射线的 `dt`（长度）、球面上的 `dω'`（立体角） |
| 哪个积分最贵 | 内散射的 `dω'`——它套着一个完整的辐亮度场（递归） |
| 能不能直接积 | 不能：5 维、含未知量、边界是几何 |
| 用什么替代 | 蒙特卡洛：一次采样替换一次积分，期望相等 |
| 距离按什么抽 | `p(t) = σt·T(0,t)`（消光 × 透射），闭式反演 1 次 `log` |
| 方向按什么抽 | `p(ω',ω)`（相函数），闭式反演 + 1 次均匀 `φ` |
| 权重是多少 | 距离：`σs/σt = albedo`；方向：**1**（因为 pdf 就是相函数） |
| 内积分在代码哪 | 不是独立变量，而是**下一次循环迭代**（§7.9） |
| 雾会不会吃掉弹射预算 | 会：一次散射 = 一个 `maxDepth` 名额，且截断**有偏变暗**（§7.10） |
| 最大的坑 | 距离采样之后**再乘一次 T**（双重吸收，§9-①） |

## 1. 记号与约定

| 符号 | 含义 | 单位 |
|---|---|---|
| `L(x, ω)` | 点 `x` 处、沿**传播方向** `ω` 的辐亮度（radiance） | `W·m⁻²·sr⁻¹` |
| `σa` | 吸收系数 | `1/m` |
| `σs` | 散射系数 | `1/m` |
| `σt = σa + σs` | 消光系数 | `1/m` |
| `albedo = σs/σt` | 单次散射反照率，`0`=纯吸收，`1`=纯散射 | 无量纲 |
| `p(ω', ω)` | 相函数：从传播方向 `ω'` 散射到 `ω` 的角分布 | `1/sr` |
| `Le(x, ω)` | 介质自发光 | `W·m⁻²·sr⁻¹` |
| `T(a, b)` | 透射率 | 无量纲 |
| `τ(a, b)` | 光学厚度 | 无量纲 |

**三条约定，全篇不变：**

1. `ω` 一律是**光的传播方向**（光往哪走），不是「从表面指向光源」的方向。因此前向散射 = `ω' ≈ ω`（夹角 0），HG 的 `g > 0` 峰在 `cosθ = 1`。
   pbrt 等文献常用「朝向观察者/光源」的约定，两者差一个负号，等价——但**混用会直接把光柱画反**。
2. 度量单位必须自洽：`σt` 是 `1/m`、`dt` 是 `m`，所以 `σt·dt` **无量纲**。这是 `exp(-τ)` 成立的前提，也是 §6 里「概率密度」成立的前提。
3. 推导积分形式时，把射线写成 `x(t) = o + t·d`（`o` = 相机，`d` = 视线方向，`t ≥ 0`），并记 `L(t) := ` 在 `x(t)` 处**朝相机传播**的辐亮度。这样 `L(0)` 就是相机看到的像素值，不必在符号上纠缠「正向/反向」。

## 2. 微分形式：一束光穿过介质时发生了什么

```
(ω·∇) L(x,ω) = − σt(x)·L(x,ω)                       ① 消光
                + σa(x)·Le(x,ω)                     ② 发射
                + σs(x)·∫_{S²} p(ω',ω)·L(x,ω') dω'  ③ 内散射
```

左边是「辐亮度沿 `ω` 方向的变化率」（单位：辐亮度 / 米）。右边三项各有一个 `1/m` 的系数，所以每一项都是「每走一米，辐亮度被改变多少」。

### 2.1 ① 消光项 `−σt·L`

**物理意义**：这一束光在 `dt` 长度内，有 `σt·dt` 的比例**从这一束里消失**。

**为什么是 `σt` 而不是 `σa`**：因为「消失」有两种原因，对**这一束**来说没有区别：

- **吸收**：光子能量转成热/其它形式，真的没了；
- **外散射**：光子还在，但被偏折到别的方向，不再属于「沿 `ω` 前进的那一束」。

所以两者在损失项里**相加**。这也是 RTE 最容易被误解的一处：`σt` 是「从这一束里离开」的速率，不是「能量消失」的速率——散射出去的光子会在 ③ 里被别人捡回来。

**数学性质**：单独存在时可解析积分，得到 Beer–Lambert 定律 `L = L₀·e^(−σt·d)`。

**数值性质**：这是方程里唯一**零方差**的部分——不需要采样，直接 `exp` 算。所有实现都会尽量把透射率解析化（同质雾、高度雾），只有异质介质才退回随机估计（§7.5）。

### 2.2 ② 发射项 `+σa·Le`

**物理意义**：介质自己发光。每走一米，辐亮度增加 `σa·Le·dt`。

**为什么系数是 `σa` 而不是 `σs` 或 `σt`**：这是 Kirchhoff 定律在散射介质里的推广——**只有能被吸收的介质才可能发射**。一个只有散射（`σa = 0`）的介质不产生任何新能量，它只会把光搬来搬去。

对雾、烟、大气这类介质，`Le = 0`，这一项恒为零。真正「发光的雾」在物理上意味着介质被激发（火焰、等离子体），或者你在用 `Le` 去近似一个体积内的光源集合。**这一项的工程价值很低**，但理解它是理解「能量守恒」的钥匙（见 2.4）。

### 2.3 ③ 内散射项 `+σs·∫p·L dω'`

**物理意义**：从**所有其它方向** `ω'` 来的光，被介质偏折到 `ω` 上，为这一束贡献能量。

三个因子各有明确含义：

| 因子 | 含义 |
|---|---|
| `σs` | 每米发生散射的**概率**（只有散射部分能改变方向，吸收不算） |
| `p(ω',ω)` | 「从 `ω'` 来的光，落到 `ω` 的**角分布**」——不是常数，所以它在积分**里面** |
| `L(x,ω')` | 从 `ω'` 方向到达该点的辐亮度（**未知量**，这正是方程要求解的东西） |

**这一项是全部复杂度的来源**，原因有三：

1. **它套着一个完整的、需要求解的辐亮度场** `L(x,ω')`（自引用）；
2. 它是**球面积分**，与外面的距离积分构成 5 维（方向 2 维 × 距离 1 维 × 像素 2 维）；
3. 它是**唯一有噪声**的来源——① 与 ② 都可以解析算，只有 ③ 必须采样。

**丁达尔效应（光柱）就是这一项的直接产物**：光柱不是物体，是「③ 在可见性非零的区域里的取值」。

### 2.4 三项的能量账（一个必须有结论的问题）

有人会问：散射既不吸收也不发射，为什么 ① 里有它、③ 里也有它，能量会不会算错？

把三项对**全方向积分**（求总能量密度的变化率），用相函数的归一化 `∫_{S²} p(ω',ω) dω = 1`：

```
∫ [−σt·L + σs·∫p·L dω'] dω
  = −σt ∫L dω + σs ∫∫ p(ω',ω)L(x,ω') dω' dω
  = −σt ∫L dω + σs ∫L dω'            ← 内层积分归一化后等于 1
  = −(σt − σs) ∫L dω
  = −σa ∫L dω
```

**结论：散射项在总能量里精确抵消，唯一真正的能量损失是吸收 `σa`。** 这一条是判断实现是否正确的最硬标准——如果你加了雾以后画面整体变亮或变暗，且不是 `Le` 造成的，那一定是 ① 和 ③ 的记账错了（典型：§9-① 的双重吸收）。

## 3. 透射率：贯穿全式的「影子项」

`T` 不单独构成一项，但它出现在**每一次**积分里，所以单独讲。

```
T(a,b) = exp(−τ(a,b)),      τ(a,b) = ∫_a^b σt(x(s)) ds
```

**物理意义**：一束光从 `a` 走到 `b` 而**不发生任何消光事件**的概率。等价地，它是「从 `b` 出发沿反方向能看见 `a` 的那部分能量比例」。

三条性质决定了它在实现里的地位：

| 性质 | 数学 | 用途 |
|---|---|---|
| **可乘性** | `T(a,c) = T(a,b)·T(b,c)` | 多次遮挡、分段积分直接连乘 |
| **有界单调** | `T ∈ (0,1]`，且 `T` 随距离递减 | **可以当概率用** → 距离采样的合法性来源 |
| **微分关系** | `dT/dt = −σt·T` | 说明 `σt·T` 是归一化的概率密度 |

**第二行是全部采样理论的支点**：正因为 `T ≤ 1` 且单调，`σt·T` 才能归一化成概率密度函数（§6.3）。如果 `T` 可以大于 1，这套算法就不成立了。

**对雾的实现选择**：

| 介质 | `τ(a,b)` 怎么算 | 成本 |
|---|---|---|
| 均匀雾 | `σt·(b−a)` | 1 次乘 |
| 指数高度雾 | 解析积分（`β(y)=β0·e^{−(y−y0)/H}` 的闭式） | 1 次 `exp` |
| 异质密度（3D 纹理/噪声） | ratio tracking 估计 | 8~30 次采样 |

## 4. 积分形式：沿射线解出来

### 4.1 推导

把 ② ③ 合称**源函数**（source function）：

```
S(x,ω) = σa(x)·Le(x,ω) + σs(x)·∫_{S²} p(ω',ω)·L(x,ω') dω'
```

（单位：辐亮度 / 米——「每米产生多少辐亮度」）

沿射线参数化后，RTE 变成一元线性微分方程。采用 §1 的约定（`L(t)` = 朝相机传播的辐亮度），沿**传播方向**积分可得：

```
L(0) = T(0,s)·L(s)  +  ∫₀ˢ T(0,t)·S(t) dt
        └────┬────┘     └────────┬────────┘
          ④ 表面项            ⑤⑥ 源项积分
```

> 符号说明：因为 `L(t)` 是朝相机传播的、而 `t` 是朝场景增长的，推导时会出现一个符号翻转（`dL/dt = σt·L − S`），积分因子取 `e^(−τ)` 后得到上式。若把 `ω` 取成「指向相机」，则直接得到标准的 `dL/ds = −σt L + S`，两种写法只差参数方向，结果相同。**结论不变**：远端的光被近端的介质衰减，近端的源在到达相机前也被衰减。

### 4.2 三个部分的物理意义

```
L(相机) = T(0,s)·L_surface                          ← ④ 透过雾看到的表面
        + ∫₀ˢ T(0,t)·σa(t)·Le(t) dt                 ← ⑤ 沿途的介质自发光
        + ∫₀ˢ T(0,t)·σs(t)·[∫p·L dω'] dt           ← ⑥ 沿途的介质散射光
```

| 项 | 物理意义 | 直观对应 | 方差 |
|---|---|---|---|
| ④ `T·L_surface` | 雾后面的表面，被雾衰减后剩下的亮度 | 远景变灰变暗、颜色去饱和 | 0（由表面部分决定） |
| ⑤ 发射积分 | 沿途每一段介质的自发光，各自被衰减到相机 | 火焰、发光的烟 | 低 |
| ⑥ 散射积分 | 沿途每一段把别处的光散射进视线 | **光柱、雾中光晕** | **高** |

**④ 的地位常被低估**：它是「雾会遮挡」的唯一体现。只做 ⑥ 不做 ④ 的方案（比如把光柱当后处理叠加），画面会出现「光柱有、但远景不变灰」的割裂感。④ 和 ⑥ 必须成对，才能自洽。

### 4.3 积分区间的物理意义

`s` 是射线第一次打到表面的距离（没打到则取远平面）。区间 `[0,s]` 再与**介质支撑集**（`σt > 0` 的区域）取交集，才是有效区间：

| 介质形态 | 有效区间 | 说明 |
|---|---|---|
| 无界（高度雾、大气） | `[0, s]` | 全段都是介质 |
| 有界（雾盒/体积云） | `[0,s] ∩ [t0,t1]` | `t0/t1` = 射线进入/离开该体积 |
| 多体积重叠 | 多段子区间 | 消光相加，逐段积分 |

**关键：区间由密度决定，不由光照决定。** 一个被完全遮住的雾团仍然有完整的积分区间，只是 `S = 0`。这一点是「通用体积渲染」与「只画已知光束」的方案（见调研文档 §4.6）最本质的区别。

## 5. 相函数：内散射积分的核

`p(ω', ω)` 描述「从 `ω'` 来的光，有多大概率被偏折到 `ω`」。它是 ③ 里唯一的**角分布**，位置在积分号**内部**。

### 5.1 三条性质

| 性质 | 式子 | 物理含义 |
|---|---|---|
| **归一化** | `∫_{S²} p(ω',ω) dω = 1` | 散射不增减能量，只重分配（§2.4 的支点） |
| **互易** | `p(ω',ω) = p(ω,ω')` | 光路可逆 |
| **各向异性** | 由 `g` 描述 | `g = ⟨cosθ⟩`，`g>0` 前向、`g<0` 后向、`g=0` 各向同性 |

### 5.2 两种常用形式

**各向同性**：

```
p = 1/(4π)                     ← 全方向等概率，真实雾/霾接近这个
```

**Henyey–Greenstein（HG）**：

```
p(cosθ) = (1 − g²) / (4π·(1 + g² − 2g·cosθ)^1.5)
```

`g` 的直观量级：

| `g` | 观感 |
|---|---|
| `0` | 光柱从各个角度看亮度接近 |
| `0.3 ~ 0.6` | 迎光看明显更亮（教堂光柱的常用档） |
| `0.8+` | 只在很接近逆光时可见，前向极强 |

### 5.3 为什么它在积分里面，而不是外面

因为它改变的是**方向的分布**，不是总量。如果它是常数（各向同性），那 `∫p·L dω' = (1/4π)∫L dω'`，就能提到积分外面；一旦有各向异性，每个入射方向 `ω'` 的权重不同，就必须留在内层对 `ω'` 求积。

**这条直接决定了实现**：你必须**按 `p` 采样方向**（而不是均匀采样方向再乘 `p`），否则方差会放大几十倍（§6.6）。

## 6. 为什么能用采样代替积分

这一节是全文的核心：**凭什么把两个积分换成几次随机抽样，结果还是对的。**

### 6.1 先看为什么不能直接积

| 障碍 | 具体表现 |
|---|---|
| **维度高** | 每次弹射要 1 维（`dt`）+ 2 维（`dω'`），加像素 2 维 = 5 维 |
| **积分域无界** | `t` 可以到无穷远（逃逸到天空），`s` 由几何决定 |
| **被积函数未知** | `L(x,ω')` 正是要求解的量（自引用） |
| **不光滑** | 可见性 `V` 是二值的，在阴影边缘有跳变 |

稠密网格法在 5 维上会指数爆炸，且无法处理跳变。所以必须换一套估计方法。

### 6.2 蒙特卡洛的基本恒等式

设 `X` 是从概率密度 `p(x)` 抽的随机变量，`f` 是任意可积函数，则

```
E[ f(X)/p(X) ] = ∫ f(x) dx
```

也就是说：**「按 `p` 抽一次、除以 `p`」的期望，恰好等于积分值。**

于是「算积分」变成「抽 N 次取平均」：

```
I ≈ (1/N) · Σᵢ f(xᵢ)/p(xᵢ)
```

这就是全部的魔法。它成立只依赖两件事：**`p` 是概率密度**（`∫p = 1`）、**`f/p` 可求值**。

### 6.3 三个必须满足的条件（本项目逐条对应）

| 条件 | 含义 | 本项目怎么满足 |
|---|---|---|
| **`p > 0` 在 `f ≠ 0` 处** | 不能「抽样抽不到有用区域」 | `σt·T > 0` 当介质存在；`p(ω',ω) > 0` 对 HG 处处为正 |
| **`p` 可采样**（CDF 可逆或可拒绝） | 能从一个均匀随机数造出 `p` 的样本 | 距离：闭式反演（1 次 `log`）；方向：HG 闭式反演 + 均匀 `φ` |
| **`f` 可求值** | 给定样本能算出被积函数 | `σa/σs/σt` 来自 UBO/纹理；`Le` 常数；`L` 由**路径的后续**提供（§6.5） |

第三行是体积渲染的特殊之处：`f` 里含未知的 `L`，但**它不需要「就地求出」**——它由「继续走的那条路径」的返回值提供。这是「递归估计」而非「解析求值」。

### 6.4 距离采样为什么合法：`σt·T` 是概率密度

令 `p(t) = σt(t)·T(0,t)`，验证归一化：

```
∫₀^∞ σt(t)·T(0,t) dt = ∫₀^∞ −dT/dt dt = 1 − T(∞)
```

- **有界介质**：`T(∞) = 0`，所以积分恰好等于 1——`σt·T` 是严格归一化的概率密度；
- **无界介质**（指数高度雾这类）：`T(∞) > 0`（实测某方向上 `T(∞) ≈ 0.767`，见 §6.8），于是 `σt·T` 只积到 `1 − T(∞)`，剩下的概率质量对应「**永不碰撞、直接逃逸**」。这不影响无偏性：逃逸那部分的权重是 1（§6.7），与缺失的概率质量精确抵消。

**它严格归一化，所以是合法的概率密度**——这正是 §3「`T ≤ 1` 且单调」的用处。

于是估计散射积分时，抽 `t ∼ σt·T`，权重为

```
f(t)/p(t) = [T·σs·(∫pL dω')] / [σt·T] = (σs/σt)·(∫pL dω') = albedo × (方向积分)
```

`T` 被约掉了——**这就是为什么距离采样之后不能再乘 `T`**：吸收已经被「抽到这么远」这个低概率隐含进去了。多乘一次就是双重吸收（§9-①，实测会掉到 73% 亮度）。

### 6.5 方向采样：`p` 就是 pdf，所以权重是 1

方向积分 `∫p(ω',ω)L(ω')dω'` 的核就是相函数本身，所以直接取 `pdf = p`：

```
抽 ω' ∼ p(·,ω)    ⟹   权重 = p/pdf = 1
```

这是「完美重要性采样」的特例：**pdf 与被积函数形状完全一致**，方差只剩 `L` 本身的变化。

而 `L(ω')` 的采样值从哪来？——**从「沿 `ω'` 继续走」的那条路径来**。所以方向积分不是「扫一遍所有方向」，而是「抽一个方向，把它后面的一切都算进来」。这就是为什么整个算法是一个循环：每一轮既结算当前顶点的直接光，又替上一个顶点推进了它的方向积分。

> 代码形态（为什么没有独立的「内积分变量」）见 §7.9；它如何消耗 `maxDepth`、以及由此带来的有偏变暗见 §7.10。

### 6.6 为什么不能「按亮度采样」

直觉上「亮的地方更该被采到」是对的（那就是重要性采样），但**不能对未知量采样**：

```
要解的就是 L  ⟹  用 L 当 pdf  ⟹  循环论证
```

所以只能按**已知的、且与贡献强相关的因子**采样。把被积函数拆开看：

```
贡献 = T · σs · p · L
        └──┬──┘  └┬┘ └┬┘
         已知    已知  未知
```

| 维度 | 已知的因子 | 是否用作 pdf |
|---|---|---|
| 距离 | `σt·T`（含 `σs` 的比例） | ✅ 已用 |
| 方向 | `p` | ✅ 已用 |
| 光源选择 | 光源功率 | ⚠️ 本工程是均匀选（可优化，§8.3） |
| 光照本身 | `L` | ❌ 未知，只能靠已知代理（等角采样、路径引导） |

> **「按贡献采样」的全部技术，都是在找「已知的、与贡献强相关的代理」来替代未知的 `L`。** 例如等角采样（equiangular sampling）利用「点光源的 `L = I/r²` 有解析式」，把「距离」按入射辐亮度抽——这就把窄光束的方差从「命中率 `P`」转成了「几何项」，是本领域最经典的方差缩减手段。

### 6.7 「表面 vs 介质」赛跑的无偏性

这是最容易让人怀疑「这不就是碰运气吗」的地方。证明很直接：

```
抽 t ∼ σt·T（覆盖整条射线，含无穷远）
若表面在 t 之前（s < t）→ 走到表面，贡献 L_surface，权重 1
若 t < s              → 在 t 处散射，贡献 albedo × (方向积分)，权重已含

P(走到表面) = P(t > s) = T(0,s)
E[贡献] = T(0,s)·L_surface + ∫₀ˢ (σs/σt)·σt·T·(方向积分) dt
        = ④ + ⑥    ✓ 与 §4.2 的积分形式逐项相等
```

**关键在「P(走到表面) 恰好等于 T」**：所以表面项的权重是 1，而不是 `T`。这就是「透射率被概率吸收了」的严格证明。

### 6.8 实测验证（本工程）

`Tools/fog_math_probe.py` 用 40 万次采样验证了上面几个关键命题（`β0 = 0.03 /m`、`H = 8 m`、弦长 30 m）：

| 命题 | 实测 | 理论 | 结论 |
|---|---|---|---|
| 无事件概率 = `T(L)` | 0.7296 | 0.7292 | ✅ 偏差 3.9e-4 |
| 散射项无偏（权重 = `albedo`） | 0.1622 | 0.1625 | ✅ 偏差 2.6e-4 |
| 表面项权重 = 1 | 2.1888 | 2.1876 | ✅ |
| **再乘一次 `T` 会偏暗** | 1.5961 | 2.1876 | ❌ 掉到 **73.0%** ≈ `T`，印证 `T²` 偏差 |

## 7. 代码实现

### 7.1 主循环骨架

```glsl
vec3 L = vec3(0.0), beta = vec3(1.0);
vec3 o = cameraPos, d = rayDir;
for (int depth = 0; depth < maxDepth; depth++) {
    // tmin：只有首段用近裁剪面，后续弹射必须从 0 起（否则近处几何会被跳过）
    float tmin = (depth == 0) ? nearPlane : 0.0;

    // ① 距离采样：这一段会不会撞到雾，撞在多远
    float t_med = mediumSampleDistance(o, d, farPlane);   // ≥ farPlane 表示本段无碰撞

    // ② 只搜 [tmin, t_med]：雾事件之前有没有表面
    rayQueryEXT rq;
    rayQueryInitializeEXT(rq, tlas, 0u, 0xFF, o, tmin, d, min(farPlane, t_med));
    // ... 现有 candidate 循环（镂空 / 玻璃）不变 ...

    // ③ 比赛：谁更近
    if (committed && hitT < t_med) {
        L += beta * emission(hit);                        // 表面自发光
        L += beta * neeAtSurface(hit);                    // 直接光（阴影射线要含雾透射）
        beta *= sampleBSDF(hit) * NdotL / pdf;            // 现有 BSDF 逻辑
        o = offset(hit);                                  // 起点复位
    } else if (t_med < farPlane) {
        vec3 P = o + t_med * d;
        beta *= sigmaS(P) / sigmaT(P);                    // = albedo（第 1 条记账规则）
        L += beta * neeAtMedium(P, d);                    // 相函数 × Li × 透射（含硬币权重，§7.4）
        d = samplePhase(d, g);                            // 权重 = 1（第 2 条记账规则）
        o = P;
    } else {
        // 逃逸：到 farPlane 的透射率。注意这里**不乘** T 是另一种合法约定（§6.7），
        // 二选一即可；本项目建议与「表面命中权重=1」保持一致 → 不乘。
        L += beta * envRadiance(d);
        break;
    }

    // ④ 俄罗斯轮盘
    if (depth > 3) { float q = min(max3(beta), 0.95); if (rand() >= q) break; beta /= q; }
}
```

**和现有表面 PT 的关系**：`pathtrace.glsl:949-1260` 的循环形状可以直接沿用，只需插入四处（§7.6 的表格）。

### 7.2 距离采样（闭式，1 个随机数）

```glsl
// 均匀介质
float t = -log(1.0 - rand(seed)) / sigmaT;

// 指数高度雾：反演解析光学厚度（见调研文档 §5.3）
// |dy| > ε:  t = -(H/dy) · log(1 - tauStar/A)
// |dy| ≤ ε:  t = tauStar / (beta0 * exp(-(y-y0)/H))
```

要点：

- `u ∈ (0,1)` 不能取到 0 或 1（`log(0)` / `log(1)`）；
- `dy → 0` 必须单独兜底，否则 `H/dy` 溢出；
- 采样后**不乘 `T`**（§6.4）。

### 7.3 方向采样（HG 反演 + 局部坐标系）

```glsl
// 2 个随机数 → 散射角
float u1 = rand(seed), u2 = rand(seed);
float cosTheta = (1.0 + g*g - pow((1.0 - g*g)/(1.0 - g + 2.0*g*u1), 2.0)) / (2.0*g);
float sinTheta = sqrt(max(0.0, 1.0 - cosTheta*cosTheta));
float phi = 2.0 * PI * u2;

// 在当前方向 d 的局部坐标系里旋转
vec3 T, B;
createONB(d, T, B);                       // pathtrace.glsl:157-163
vec3 newDir = cosTheta*d + sinTheta*(cos(phi)*T + sin(phi)*B);
```

要点：

- `g ≈ 0` 时公式除零 → 退化成各向同性 `cosTheta = 1 − 2u1`；
- **pdf = `p`，所以 `beta` 不变**（权重 1）；
- `createONB` 在 `pathtrace.glsl:157` 已有，可直接复用；半球采样 `cosineSampleHemisphere`（`:164`）是同一套路，只是分布不同。

### 7.4 碰撞点的 NEE

```glsl
// 选光源（现状：均匀 + ×lightCount；见 §8.3 的改进）
uint li = uint(rand(seed) * float(lightCount)) % lightCount;
VPT_Light Lgt = lights[li];
vec3 toL; float dist; vec3 Lcolor;
sampleLightContribution(Lgt, P, toL, dist, Lcolor);

// 相函数（方向约定见下表；写反会让光柱在迎光时变暗）
float cosTheta = dot(toL, d);              // d 是「眼→点」，toL 是「点→光源」
float phase = hgPhase(g, cosTheta);

// 阴影射线：玻璃彩色透射 × 雾透射
vec3 trans = traceShadowTransmission(P, toL, dist, isInsideVolume, volumeSigma);
trans *= fogTransmittance(P, toL, dist);

// 光源采样补偿：均匀选灯 → ×lightCount
// 50/50 硬币（灯 vs 环境）→ ×2.0；若改成真 MIS，则换成平衡启发式权重
L += beta * phase * Lcolor * trans * float(lightCount) * 2.0;
```

**方向符号是这一节最容易错的地方**：

| 量 | 含义 |
|---|---|
| `d` | 视线方向「眼 → 点」（射线参数增长的方向） |
| `toL` | 从点指向光源（与光传播方向相反） |
| 光的传播方向 | `−toL` |
| 朝相机传播的方向 | `−d` |
| 散射角 `cosθ` | `dot(−toL, −d) = dot(toL, d)` |

所以 `cosθ = dot(toL, d)`。**写反的后果**：光柱在看向太阳时反而变暗——一眼可辨，但很容易被误当成「相函数参数不对」。

### 7.5 透射率估计（三种介质）

| 介质 | 代码形态 | 复杂度 |
|---|---|---|
| 均匀 | `exp(-sigmaT * dist)` | O(1) |
| 高度雾 | 解析积分 → `exp(-tau)` | O(1) |
| 异质 | ratio tracking：`w *= (1 - sigmaT(t)/sigmaBar)` | 8~30 次采样 |

**异质的 majorant（`sigmaBar`）**：必须取该区域密度上界，否则估计有偏。取法有三种，成本递增：

1. 全局最大密度（简单、保守、步数多）；
2. 包围盒最大密度（按体积分开）；
3. **低分辨率 majorant 网格**（pbrt 的 `GridDensityMedium` 做法，空区域直接跳过）。

### 7.7 能量记账的三条硬规则

1. **碰撞点乘 `albedo`**（`σs/σt`）：散射比例；`albedo=1` 的白雾不损失能量。
2. **方向采样权重 = 1**：pdf 就是相函数。
3. **距离采样后不乘 `T`**：吸收已在概率里（§6.4）。

> 违反任意一条，画面都会「看起来能跑，但亮度不对」，而且很难反查——所以建议实现时加一个 `fogDebugMode`，直接输出 `T`、`albedo`、`t_med/hitT` 三张图对账。

### 7.8 终止条件

```glsl
// 俄罗斯轮盘（现有 pathtrace.glsl:1253-1259）
float pcont = min(max3(beta) + 0.001, 0.95);
if (rand(seed) >= pcont) break;
beta /= pcont;
```

体积渲染额外需要一条**散射次数上限**：浓雾时 `albedo ≈ 1`，`beta` 几乎不衰减，轮盘会一直放行 → 路径永不终止 → GPU 时间尖峰。建议上限 4 次。

### 7.9 内积分在代码里是怎么算的：从递归到摊平

数学上，散射积分的内层是**递归**的：

```
inner(P, d) = ∫ p(ω',ω)·L(P,ω') dω'
            ≈ (1/N) · Σᵢ  [p(ω'ᵢ,ω)/pdf(ω'ᵢ)] · traceRadiance(P, ω'ᵢ)     ← 递归调用
```

如果照字面实现，代码会长这样：

```glsl
float inner = 0.0;
for (int i = 0; i < N; ++i) {
    vec3 wp = samplePhase(d, g);
    inner += p(wp, d)/pdf(wp) * traceRadiance(P, wp);    // 递归
}
```

但真实的 `pathtrace.glsl` **不是递归**，而是同构的一段循环：

```glsl
for (int depth = 0; depth < maxDepth; depth++) {
    ...
    L += beta * nee(...);        // 结算当前顶点
    d = samplePhase(d, g);       // 为内积分抽一个方向
    // 下一轮迭代 == 那个方向的 traceRadiance
}
```

**关键结论：内积分不是一个独立的变量，而是被“摊平”进了循环的后续迭代。**

- 内积分的**样本值** = 从 `P` 出发沿 `ω'` 的**后续所有顶点贡献之和**；
- 你无法在代码里切出“这部分 `radiance` 属于 P 点的内积分”——所有顶点共用同一个 `radiance` 和同一个 `beta`；
- 归因是**隐式**的，靠 `beta` 的时间顺序：`P` 之后每一条 `L += beta * ...`，其 `beta` 里已经含了 `P` 点的 `albedo × 相函数`，所以它们在数学上就是 `P` 点内积分的样本。

对照表：

| 数学写法 | 代码里的对应 |
|---|---|
| `∫ p·L dω'` | 下一次循环迭代（一次 `samplePhase`） |
| `L(P,ω')` 的采样值 | 从 `P` 沿 `ω'` 的后续全部 `L +=` 之和 |
| `p/pdf` | 恒为 1（§6.5） |
| 递归深度 | `depth` 自增 |

**为什么不写成递归**（三个理由都成立，缺一不可）：

1. **GPU 不支持深递归**：栈空间与 warp 发散会让性能崩掉；迭代是平的。
2. **`beta` 天然承接权重**：递归需要把返回值一路乘回来，而迭代让 `beta` 边累积边结算，效果等价但少一次回传。
3. **轮盘需要全局视角**：终止决策要看“整条路径还剩多少能量”，递归写法里这个信息在栈上，迭代写法里就是一个变量。

**一个推论**：调试时想验证“雾散射是否生效”，**不要**去找 `inner` 变量——按顶点打日志（顶点类型、`t_med`、`albedo`、`beta` 模长），是唯一可行的方式。

### 7.10 内积分对 `maxDepth` 的影响：雾会吃掉弹射预算

**一次循环迭代 = 一个路径顶点 = 一个弹射名额。** 雾散射与表面弹射**同权**，没有免费名额。

#### 影响一：预算被雾吃掉，画面有偏变暗

| 路径（`maxDepth = 4`） | 命运 |
|---|---|
| 表面 → 表面 → 表面 → 逃逸 | ✅ 正常 |
| 表面 → **雾** → **雾** → **雾** | ❌ 名额用完，到不了后面的彩窗 |

原本能打到彩窗、贡献一次彩色间接光的路径，被三次雾散射消耗掉了。**这是有偏变暗，不是噪声**——相当于把 Neumann 级数的尾部直接砍掉（§6 的路径展开）。

#### 影响二：`maxDepth` 截断有偏，轮盘无偏

| 终止方式 | 是否无偏 | 原因 |
|---|---|---|
| 俄罗斯轮盘（§7.8） | ✅ | `beta /= pcont` 补偿了被砍掉的那部分概率 |
| `maxDepth` 用完 | ❌ | 直接丢尾部，没有任何补偿 |

浓雾 `albedo ≈ 0.9 ~ 1` 时 `beta` 几乎不衰减，轮盘几乎不触发，于是**绝大多数路径是被 `maxDepth` 砍断的**——画面系统性偏暗，且 `maxDepth` 越小越暗。这个现象很容易被误判成“雾的 albedo 调错了”。

#### 建议：两个独立计数器

```glsl
int depth       = 0;   // 总弹射上限（管成本）
int fogScatters = 0;   // 雾散射上限（防止在浓雾里无限打转）
```

分开的好处：可以给表面留足预算，同时防止浓雾下的 GPU 时间尖峰。

| 场景 | `maxDepth` | `fogScatters` |
|---|---|---|
| 只做丁达尔（薄雾、单次散射为主） | 保持现状（4~5） | 1~2 |
| 一般体积雾 | **+1 ~ +2** | 4 |
| 浓雾 / 体积云 | **+3 ~ +4** | 6~8 |

#### 影响三：内积分每条路径只有 1 个样本

“抽一个方向”的直接代价：`∫p·L dω'` 每帧每像素只被估一次。所以：

- 降它的噪声 → **加路径数**（spp、帧数、空间邻域），不是“每条路径多抽几个方向”；
- 降它的成本 → 减少顶点数（`maxDepth`），但这会引入偏差（见影响一、二）。

唯一的例外是**分裂（splitting）**：在散射点同时抽 2~4 个方向、各开一条子路径。降方差明显，但成本是“多出来的光线”，且与 DLSS RR 的配合需要实测。实时实现通常不做，因为宁愿把预算花在更多像素上。

## 8. 噪声、方差与收敛

### 8.1 方差的解析形式

对估计量 `F = f(X)/p(X)`：

```
Var(F) = ∫ f²/p − (∫f)²
相对标准差 = sqrt( (∫f²/p − I²) / N ) / I
```

两个结论：

- **`p ∝ f` 时方差为零**（理想）；
- 相对误差 ∝ `1/√N`——想降一半噪声要 4 倍样本。

对「二值命中」这类估计（概率 `P`、非 0 即 `c/P`）：

```
相对标准差 ≈ sqrt( (1−P)/(N·P) )
要压到 10%：N ≈ 100/P
```

### 8.2 三种方差源（按大小）

| 来源 | 表现 | 缓解 |
|---|---|---|
| 碰撞/不碰撞（二值） | 稀疏噪点 | 提 spp、时域累积 |
| 可见性 0/1（阴影边缘） | 阴影边缘闪烁 | MIS、比例估计 |
| 相函数方向 | 相邻像素方向完全不同 | 空间滤波无效，只能靠时间/更多 spp |

### 8.3 本工程三处「未加权的骰子」（明确的方差来源）

| 位置 | 现状 | 更优 |
|---|---|---|
| 选光源 | 均匀选 + `×lightCount`（`:1113-1114, 1144`） | 按功率加权 |
| 灯 vs 环境 | 50/50 硬币 + `×2.0`（`:1108, 1144, 1186`） | 按估计贡献动态选（真 MIS） |
| 相函数 | HG 采样 | 已最优（pdf = p） |

前两处是「亮区帧间抖动」的已知来源之一（见 `doc/DLSS_RR亮区抖动分析.md`）。

### 8.4 与 DLSS RR 的关系

本工程**没有** PT 自己的历史缓冲（`pathtrace.glsl:1269` 每帧覆盖写），时域累积完全由 DLSS RR 承担。这对体积噪声有三个限制：

1. RR 的时域窗口通常只有十几帧（指数衰减），不是几百帧；
2. RR 按**表面**运动矢量重投影，雾没有自己的运动；
3. RR 的空间核按法线/深度加权，假设邻像素属于同一表面。

所以：**距离维度的噪声（低频）RR 能压；方向维度的噪声（高频）压不住。** 需要 `N ≈ 100/P` 的场景（窄光束、薄雾）无法靠 RR 收敛，必须靠确定性采样或提 spp。

## 9. 常见误区

| # | 误区 | 后果 | 正确做法 |
|---|---|---|---|
| ① | 距离采样后再乘一次 `T` | 双重吸收，雾整体偏黑，且随 `β0` 非线性 | 只保留一处（§6.4）；实测掉到 73% |
| ② | 把 pdf 当能量乘进去 | 整体偏亮，且随相函数形状变化 | 权重是 `f/pdf`，不是 `pdf` |
| ③ | NEE 与相函数采样都估同一个积分却直接相加 | 直接光被算两遍 | MIS 或选择概率补偿 |
| ④ | 方向向量未归一化 | `σt·t` 不再是无量纲，雾浓度量级错 | 进入积分前 `normalize` |
| ⑤ | 把 `t` 当时间 | 单位/极限判断错误（如对 `t` 设时间上限） | `t` 是弧长（米），静态介质无时间变量 |
| ⑥ | 每段忘记复位原点 | 透射率跨越了不该跨越的距离 | `T` 从**该段起点**算起 |
| ⑦ | 把雾塞进玻璃的介质状态机 | 单介质假设被打破，嵌套时状态错乱 | 雾走独立函数/采样（调研文档 §5.5） |
| ⑧ | 用 50/50 硬币当 MIS | 方差高于真 MIS，亮区帧间抖动 | 平衡启发式 |

## 附：一句话

**体积散射方程是「三个源 + 一个边界」：消光拿走能量（可解析）、发射补回能量（便宜）、内散射把别处的光搬过来（贵，且是唯一有噪声的项）；边界是雾后面的表面。路径追踪把这个 5 维积分拆成一串局部决策——距离按 `σt·T` 抽，方向按 `p` 抽，可见性用阴影射线判，透射率解析算——蒙特卡洛的期望值保证结果在统计意义上精确等于积分本身。**
